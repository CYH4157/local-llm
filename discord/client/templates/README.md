# 範本資料夾（選用）

放入以下檔案，`!ppt` / `!word` 就會套用實驗室自己的樣式；沒有就用內建樣式。

| 檔名 | 說明 |
|------|------|
| `ppt_template.pptx` | 投影片母片。**第 1 個版面**要是「標題投影片」，**第 2 個版面**要是「標題及內容」。範本裡原有的投影片會被清掉，只保留母片。 |
| `word_template.docx` | Word 範本。會沿用它的樣式（標題 1、清單項目符號…）、頁首頁尾、邊界，內文會被清空重填。 |

做法：用 PowerPoint 開實驗室簡報 →「檢視 → 投影片母片」確認版面順序 → 另存成 `ppt_template.pptx` 放這裡。
