# lab-opencode-command：由 install-client 安裝，重新安裝時會更新
description: 校稿（台灣繁體）：簡體字、大陸用語、錯字、標點、不通順的句子
---
幫我校稿：$ARGUMENTS

**你的所有回答、建議與修改後的文字，一律使用繁體中文與台灣用語，絕對不可以出現簡體字或大陸用語。**

步驟：
1. **先用工具檢查簡體字、大陸用語、半形標點**（工具用字典比對，比你自己判斷準確）：
   - 檔案：`labdoc tw "檔名"`（Word、PPT、PDF、Excel、.md、.txt 都可以）
   - 使用者直接貼文字：先用 write 工具存成 `校稿.txt`，再執行 `labdoc tw "校稿.txt"`
   把工具列出的結果整理進第 3 步的表格。「看上下文」那一類要依文意判斷：真的是大陸用法才列入建議，台灣用法正確就略過。
2. **再自己讀內容**，找工具抓不到的問題（Word / PDF / PPT 用 `labdoc read "檔名"` 讀，.txt / .md 用 read 工具；內容很長就分段）：
   - 錯字、漏字、重複字、同音字誤用（例：「在」「再」、「的」「得」、「做」「作」、「已」「以」）
   - 工具沒收錄的大陸用語或大陸語法，例如：
     「質量→品質」「視頻→影片」「信息→資訊」「網絡→網路」「軟件→軟體」「默認→預設」
     「反饋→回饋」「渠道→管道」「落實到位→確實執行」「進行一個討論→討論」「做一個分享→分享」
     「搞定→完成」「靠譜→可靠」「立馬→馬上」「點贊→按讚」「打卡→簽到（依情境）」「高端→高階」
   - 中文句子裡的半形標點、引號：台灣用「」和『』，不用 “ ” 或 " "
   - 語意不清、太長的句子（給改寫建議）
   - 前後不一致（數字、名稱、日期、用詞）
   **不要整篇改寫**，不要改變作者的意思、專有名詞與引用原文。
3. 輸出：

**檢查結果**：簡體字 ○ 處、大陸用語 ○ 處、錯字 ○ 處、標點 ○ 處、語句 ○ 處

| # | 位置 | 原文 | 建議 | 原因 |
|---|---|---|---|---|

   最後用一兩句話給整體建議。
4. 問使用者要不要產生修正版：
   - 只修簡體字、大陸用語、半形標點（保留原本格式）：`labdoc tw "檔名" --fix`，會另存成「原檔名_台灣用語」。
   - 連錯字和語句一起修：把修正後全文寫成 `原檔名_校正.md`，執行 `labdoc word "原檔名_校正.md"`。
   原始檔案不要修改。
