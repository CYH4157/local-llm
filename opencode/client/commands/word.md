# lab-opencode-command：由 install-client 安裝，重新安裝時會更新
description: 寫 Word 文件（報告、說明、通知、申請書等）
---
寫一份 Word 文件。需求：$ARGUMENTS

步驟：
1. 有給參考檔案時，用 `labdoc read "檔名"` 讀內容（.txt / .md 用 read 工具）。
2. 缺少的資訊（姓名、日期、金額、單位）不要編造，寫成「［請填：…］」。
3. 用 write 工具把內容寫成 Markdown 檔（檔名用文件名稱，例如 `活動企劃書.md`）。可用的格式：
   - `# 文件標題`（只用一次，會置中）
   - `## 一、大標題`、`### （一）小標題`
   - 一般段落：一行一段
   - 條列：`- 項目`；表格：`| 欄 | 欄 |`；粗體：`**文字**`
   - `---` 換頁；圖片：`![圖說](圖片檔名.png)`
4. 執行：`labdoc word "活動企劃書.md"`
   - 有學校或實驗室的 Word 範本：加 `--template "範本.docx"`
   - 想改字型：`--font 微軟正黑體`（預設標楷體）
5. 回報 .docx 路徑，並列出文件裡還有哪些「［請填：…］」要使用者自己補。
   要修改就改 .md 再執行一次（加 `--force` 覆蓋舊檔）。

注意：只用 labdoc 產生 Word，不要自己寫 python-docx 程式。
