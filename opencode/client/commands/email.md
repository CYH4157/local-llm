# lab-opencode-command：由 install-client 安裝，重新安裝時會更新
description: 寫 email（給老師、行政單位、廠商、國外學者；中文或英文）
---
幫我寫一封 email。情況：$ARGUMENTS

步驟：
1. 判斷收件人和目的。缺少關鍵資訊（收件人是誰、要請對方做什麼、期限）時，先簡短問使用者，最多問 3 個問題。
   次要資訊（日期、學號、課名）不要編造，寫成「［請填：…］」。
2. 直接在對話中輸出，格式：

**主旨**：〔具體寫出事由，例如「申請延後繳交期末報告（資料結構，學號［請填］）」〕

**內文**：
（完整信件）

3. 寫法：
   - 給老師／教授：「○老師您好：」開頭，先自我介紹（系級、姓名、學號），一段講一件事，結尾「敬祝 研安」＋署名。
   - 給行政單位：「承辦人您好：」，寫清楚要辦什麼、附了什麼文件、希望何時回覆，結尾「敬祝 順心」。
   - 給廠商：寫清楚品項、數量、規格、報價或交期需求，結尾「謝謝」＋署名與聯絡電話。
   - 英文信：使用者要求或收件人是外國人時寫英文，用 "Dear Prof. ○○," 開頭、"Best regards," 結尾。
   - 語氣有禮但精簡，重點放第一段；請求要具體（日期、時間、方式）。
4. 最後提醒使用者：信件不會自動寄出，請確認「［請填］」的地方再寄。
