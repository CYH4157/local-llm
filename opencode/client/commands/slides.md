# lab-opencode-command：由 install-client 安裝，重新安裝時會更新
description: 做投影片（PowerPoint）：給主題或參考檔案
---
做一份投影片。主題或參考資料：$ARGUMENTS

步驟：
1. 有給參考檔案時，用 `labdoc read "檔名"` 讀內容（.txt / .md 用 read 工具）。
   沒給檔案就依主題寫，不確定的數據不要編，寫成「［請補充：…］」。
2. 用 write 工具把大綱寫成 Markdown 檔，檔名用主題，例如 `期中報告.md`。格式**必須**照這樣：

```markdown
# 簡報標題
報告人 · 日期

## 第一張投影片的標題
- 重點一
- 重點二
  - 子重點（前面兩個空白）
> 講者備註：這張要講的話（選用）

## 有表格的投影片
| 項目 | 數值 |
|---|---|
| A | 10 |

## 有圖片的投影片
- 說明文字
![圖說](圖片檔名.png)
```

   規則：
   - `#` 只用一次（封面）；每張投影片用 `##` 開頭。
   - 共 6–12 張；每張最多 6 個重點，每個重點不超過 25 個字，寫關鍵字不要寫長句。
   - 第二張放大綱或動機，最後一張放結論或總結。
   - 圖片只能用資料夾裡真的存在的檔案。
3. 執行：`labdoc slides "期中報告.md"`
4. 回報 .pptx 路徑和張數，並告訴使用者：想改內容可以直接說，你會修改 .md 再重新產生（重新產生要加 `--force` 覆蓋舊檔）。
   有實驗室範本時可加 `--template "範本.pptx"`。

注意：只用 labdoc 產生投影片，不要自己寫 python-pptx 程式。
