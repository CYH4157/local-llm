# lab-opencode-command：由 install-client 安裝，重新安裝時會更新
description: 寫簽呈、公文、申請書、請假單、切結書等正式文件（台灣公文格式），輸出 Word
---
寫一份正式文件。需求：$ARGUMENTS

步驟：
1. 判斷文件類型：簽呈（向上級請示）、函（對外單位）、申請書、請假或公假申請、切結書、證明書。
   使用者有給學校的範本或舊文件時，先用 `labdoc read "檔名"` 讀，照它的格式寫。
2. 人名、單位、日期、金額、文號等資料使用者沒給就寫「［請填：…］」，**不要編造**，也不要編造法規條號或校內規定名稱。
3. 用台灣公文寫法：
   - 簽呈：主旨（一句話，結尾用「，簽請　核示。」或「，請　鑒核。」）→ 說明（一、二、三…；細項用（一）（二））→ 擬辦。
   - 函：主旨 → 說明 → 辦法（需要時）。
   - 申請書：申請人資料 → 申請事由 → 申請內容（時間、地點、金額）→ 附件 → 簽名與日期。
   - 用語：「為…」「檢附…乙份」「敬請」「惠予」「依…辦理」；語句簡潔，不用口語。
4. 用 write 工具寫成 Markdown（例如 `簽呈_購置硬碟.md`）：

```markdown
# 簽呈

**主旨**：為……，簽請　核示。

## 說明
一、……
二、……
（一）……

## 擬辦
奉核後，……。

申請人：［請填］　　　　日期：［請填］
```

5. 執行：`labdoc word "簽呈_購置硬碟.md"`（預設標楷體；有學校範本加 `--template "範本.docx"`）
6. 回報 .docx 路徑，列出所有要使用者自己填的「［請填：…］」，並提醒依所屬單位的格式規定再確認一次。
