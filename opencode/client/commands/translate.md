# lab-opencode-command：由 install-client 安裝，重新安裝時會更新
description: 翻譯文件或文字（中英互譯），可輸出 Word
---
幫我翻譯：$ARGUMENTS

步驟：
1. 讀內容：PDF / Word / PPT 用 `labdoc read "檔名"`（.txt / .md 用 read 工具）；使用者直接貼文字就用貼的。
2. 方向：使用者有指定就照指定；沒指定時，中文翻成英文、其他語言翻成繁體中文（台灣用語）。
3. 翻譯原則：
   - 忠實、通順，不增刪內容；專有名詞第一次出現時保留原文，例如「大型語言模型（LLM）」。
   - 保留原本的標題、條列、表格結構。
   - 不確定的術語在後面標「〔?〕」，最後統一列出請使用者確認。
4. 長文件（超過約 3000 字）：依標題或頁碼分段翻譯。PDF 用 `labdoc read "檔名" --pages 1-5` 一次讀幾頁，
   每段翻完就用 write／edit 工具接著寫進 `原檔名_翻譯.md`，不要等全部讀完才寫。
5. 短文字直接在對話中輸出。長文件寫完後執行 `labdoc word "原檔名_翻譯.md" --font 微軟正黑體`，回報 .docx 路徑。
