# lab-opencode-command：由 install-client 安裝，重新安裝時會更新
description: 摘要文件或公告：重點、期限、要做的事（PDF / Word / PPT / Excel 都可以）
---
請摘要這份文件：$ARGUMENTS

步驟：
1. 讀檔：PDF、Word、PPT、Excel 一律用 `labdoc read "檔名"` 讀（不要用 read 工具讀這些檔案）；
   .txt、.md 用 read 工具。使用者直接貼文字就不用讀檔。
2. 輸出最後出現「只顯示前 N 字」時，代表還沒讀完：PDF 用 `--pages` 分段繼續讀（例如 `--pages 6-10`），
   每段先記下重點，全部讀完再整理。
3. 依下面格式回答（沒有的項目就寫「無」，不要編造）：

**一句話重點**：……

**重點**
- （3–7 點，保留重要數字、金額、名稱）

**日期與期限**
| 日期 | 事項 |
|---|---|
（依時間排序；已經過的標示「已過」）

**需要我做的事**
- （要繳交、填寫、報名、回覆的項目；沒有就寫「無」）

**聯絡窗口**：（承辦人、電話、email；文件裡有才寫）

4. 最後問使用者要不要存成 Word：要的話把摘要寫成 `摘要_原檔名.md`，再執行 `labdoc word "摘要_原檔名.md"`。
